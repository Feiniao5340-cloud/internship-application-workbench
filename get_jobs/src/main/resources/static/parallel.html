首次使用

  1. 双击文件夹中的“配置模型”，选择自己的Codex账号或模型API。修改模型配置后重启工作台。
  2. 填写并保存下面的个人简历事实、偏好和招呼语。
  3. BOSS用户上传图片简历，其他平台在网站上传并核对站内简历。
  4. 在平台卡片登录，先进行只筛选轮次，核对结果后手动试投一条。
  5. 单条投递成功后，按需开启平台自动投递和每日定时。

运行安排

北京时间每天07:00—16:30，整点触发各平台首页、半点触发搜索。最多三个平台同时运行，其余公平排队；每个平台内部串行。读取数和投递数按平台分别设置，均为上限。先采集评分，再按匹配度投递；过期时段不积压补跑，17点停止新增发送。

同一平台按北京时间当天去重；同公司、同岗位允许跨平台投递。应届生实习替代前程无忧；新入口核对站内简历及完成投递验收前只筛选、不发送。当前不提供拉勾适配。新平台真实投递验收通过前，不启用定时发送。
