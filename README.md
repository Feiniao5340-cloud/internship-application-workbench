# 实习投递工作台

版本：v2.1（2.1.0）。四个平台：BOSS直聘、实习僧、智联招聘、应届生实习。最多三个平台并行，独立登录、限额和暂停，按简历匹配度排序，平台内北京时间当日去重。

这是独立发布副本，个人资料与求职偏好为空，演示采用虚构数据。未包含作者的个人简历、账号、投递记录、API密钥或定时授权。不同Windows环境与招聘页面的兼容性仍需实际验证。公开分发与本地数据的边界见[隐私说明](PRIVACY.md)。

## 普通使用者

在GitHub Release附件中下载`InternshipWorkbench-2.1.0-windows-x64.zip`，不要把“Source code.zip”当安装包。完整解压到可写目录，然后双击“打开工作台.cmd”。首次弹出模型配置，随后在网页完成自己的资料与平台配置。无需安装Java、Gradle或Node，不需要作者的旧版项目目录。

本包包含Java运行时、Node和浏览器驱动；仍需本机已有Chrome或Edge。使用Codex模式需要自行安装并登录自己的Codex；使用API模式无需Codex账号，配置自己的API地址、模型和密钥。程序不提供共享算力，不附带作者账号。

初始每日定时、各平台自动投递、简历就绪、待确认自动放行都关闭。先验证只筛选，再人工确认单条投递；每个平台取得自己的成功回执后才允许自动投递。不要在不了解偏好的情况下开启自动确认待确认岗位。

详见[使用说明](使用说明.md)。源码和成品包都应保留[上游许可证](LICENSE)及第三方声明；本项目含非商业用途限制，不以MIT覆盖上游许可。

## 模型接入范围

| 使用方式 | 当前支持情况 |
| --- | --- |
| 自己安装并登录的Codex | 支持通过本机Codex程序调用，能否使用所选模型取决于本人账号权限和可用额度。 |
| OpenAI兼容的Chat Completions或Responses文本API | 支持配置自己的接口地址、模型及密钥，先通过工作台的模型连接与结构化判断检查。 |
| 提供上述兼容接口的本地模型服务 | 可以尝试接入；仍须通过结构化输出与判断检查，不能仅凭接口可访问就视为可用。 |
| 其他产品的网页/App订阅 | 当前不能直接连接。订阅不等于已经获得可调用的API；需使用该产品明确提供、并已适配的程序接口。 |
| 原生接口格式不同的模型服务 | 需要开发对应适配器，不能保证填入地址就能使用。 |

每位使用者自行提供模型账号或API额度。本项目不提供共享账号、免费算力、通用订阅转换或代登录服务。

## 开发与打包

源码依赖Java21和Gradle Wrapper。浏览器相关测试需指定`-PtestBrowser`和`-PtestDriver`；没有浏览器时跳过的测试不能算真实网页验证。

构建：在get_jobs目录执行`gradlew.bat test bootJar -x buildFrontend`。独立工作台是原生静态页面，无需旧Next.js管理中心。构建驱动任务需要npm/pnpm。

打包：`python tools/build_portable.py --java-home <JDK21目录> --node <node.exe> --driver <包含package/cli.js的目录> --output <新的输出目录>`。打包器只装配明确列出的程序与许可证，不复制开发数据库、浏览器会话、日志或作者配置，输出ZIP和SHA256。Node许可证从对应版本的官方源码取回。

提交前执行`python tools/audit_release.py .`，发布包生成时也执行路径与秘密模式检查。可通过`--private-patterns <私有JSON文件>`补充本人标识的正则表达式列表；该文件必须放在发布范围之外，姓名或路径即使转成字符编码也不能写进公开检查脚本。发布前还要检查待推送的Git历史、源码ZIP和成品ZIP中的内嵌JAR及驱动文件。检查不是完整秘密审计的替代，首次公开前仍需人工复核及独立电脑验证。

## v2.1 更新

- 普通Chrome后台运行，自动详情页不主动置前；保留手动显示浏览器处理登录/验证的入口。部分Windows环境仍可能短暂闪窗，不保证完全不抢焦点。Headless为可选方式，遇到网站验证应由使用者处理。
- 单轮故障在允许时段内自动重试一次，通知重试结果；结果未确认的发送不能盲目重发。
- 改进智联校园岗位和聊天附件回执核对，支持证据编号解析，减少模型引用原文校验失败。
- 整点首页推荐、半点关键词搜索，最多三平台同时运行；各平台限额和暂停独立。
- 可选Windows每日唤醒附带服务在线守护，启动日志按次留存。不会绕过网站验证、清除平台上限或重新启用已关闭的网页定时开关。点击“停止工作台”后守护不自动重开。
- 附带只读日报脚本：按平台统计当日去重详情读取、确认新投递、待核实投递及故障。日报单独需要Python 3.10及以上，输出到reports；公开版不包含作者的聊天自动化。

公开便携版尚未在每位使用者的电脑和账号上完成真实投递验收。请按首次使用流程验证后再开启自动发送。
